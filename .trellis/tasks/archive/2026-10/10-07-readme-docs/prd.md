# 完善 README 和用户文档

## Goal

让打开仓库的人先看到 Mosaic 现在长什么样。README 和一份用户文档用同一组真实截图做简短功能介绍。截图不打开任何文件或文件夹。

## Background

- 用户文档目前只有根目录 `README.md`，没有 `docs/`。README 已用中文写明：Windows 桌面工具，给图片和 PDF 打马赛克，导出到新文件，不覆盖原文件。后面是功能列表、快捷键、环境、`just` 命令、目录和 MIT 许可。
- 界面文字是中文（`.trellis/spec/frontend/component-guidelines.md`）。可见入口包括工具栏「打开文件」「打开文件夹」「重置」、工具「矩形」「画笔」「抓手」、颗粒大小、恢复默认、撤销、重做、导出、「设置」菜单里的「设置…」和「关于 Mosaic」。未打开文件时，主区域是空状态「拖入图片、PDF 或文件夹」，状态栏是「未打开文件」。旋转按钮只在已打开图片时出现。
- 工具栏是容器查询。内容宽度低于 1350px（窗口约 1374px）时，「打开文件」和「打开文件夹」的文字变为仅供读屏，默认 1280px 窗口里这两项只剩图标。
- 设置是整页，不是弹窗。标题「设置」，右侧「关闭」。页内说明导出文件名在原文件名后加后缀，字段是「导出文件名后缀」，默认 `_打码版`。
- 「关于 Mosaic」是弹窗。版本来自 Tauri `getVersion()`，当前 `src-tauri/tauri.conf.json` 为 `0.2.0`。浏览器里这个调用会失败，界面显示「未知」。
- 支持格式与空状态一致：JPG、JPEG、PNG、WebP、BMP、PDF。README 里的快捷键表与 `src/features/editor/useShortcuts.ts`、工具栏提示一致，本次不改这些事实。

## Requirements

- R1. README 的功能介绍改成三张真实截图，每张配一两句说明。保留现有快捷键、环境、命令、目录和许可。功能列表里已经写过、截图又能看见的入口，不要在 README 里再列一遍。
- R2. 新增 `docs/guide.md`，给使用者看。用同一组图片，写清空状态、设置页和关于弹窗上能直接看到的事，以及格式、导出不覆盖原文件、默认后缀 `_打码版`。不写安装和开发命令。README 链到这篇文档。
- R3. 三张图都来自同一次运行的桌面窗口，窗口宽度大于 1374px，使「打开文件」和「打开文件夹」的文字可见：
  - 未打开文件的主窗口（工具栏、空状态、状态栏）
  - 设置页
  - 「关于 Mosaic」，版本显示 `0.2.0`
- R4. 图片放在 `docs/images/`，README 和 `docs/guide.md` 引用这些文件，不各存一份。
- R5. 文案用中文。按钮、菜单和标题用界面上的原词。新写的句子里不用 em dash 或 en dash。
