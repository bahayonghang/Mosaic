# Redesign the application icon

## Goal

Replace the Tauri template icon with a Mosaic icon whose source image was generated by Grok `image_gen` and approved by the user. The icon files used by the window, taskbar, and Windows installers are replaced. Those surfaces update on the next `tauri dev` or `tauri build`.

## Background

Mosaic is a Windows desktop tool that mosaics images and PDFs. The product name is `Mosaic`, the identifier is `com.mosaic.desktop`, and the window title is `Mosaic`.

`src-tauri/icons/icon.png` is the Tauri template mark (cyan and amber rings on black). `src-tauri/tauri.conf.json` lines 28-40 bundle only `nsis` and `msi`, and point `bundle.icon` at `32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`, and `icon.ico`. The same directory also holds `icon.png`, `StoreLogo.png`, and the nine `Square*Logo.png` files. The frontend has no logo component and no favicon.

The UI accent is `--signal: oklch(0.62 0.19 35)` (`#e14d28`). The warm paper canvas is `--canvas: oklch(0.915 0.005 60)` (`#e5e2e0`). The page background `#fcfaf8` is too close to white for an icon plate. Token source: `src/styles/globals.css` lines 54-75. Conversion is recorded in `research/icon-pipeline.md`.

The user chose a mosaic-tile mark on a warm ground, with vermilion taken from `--signal`.

## Requirements

- R1. The mark is a few large vermilion tiles on a warm ground. The tiles stay large enough that a 16px and a 32px view still read as blocks.
- R2. Tile color is `#e14d28`. The ground is the opaque canvas color `#e5e2e0`, full-bleed to the square edges. No other colors, no text, no photo, no gradient, and no shadow.
- R3. The source is produced by Grok `image_gen` at aspect ratio `1:1`. Three candidates use three compositions. The user picks one before any file under `src-tauri/icons/` changes.
- R4. If a round produces no acceptable candidate, run one more round of three. If that round also fails, stop and leave the existing icons in place.
- R5. After approval, regenerate the desktop icon set from that source with the installed `tauri icon` command. Keep every file that is already in `src-tauri/icons/`, and keep the `64x64.png` the current CLI adds. Do not add `android/` or `ios/`. Do not edit `bundle.icon`.
- R6. Do not change the product name, the identifier, or the window title.

## Acceptance Criteria

- [ ] The user has selected one candidate, and that file is square.
- [ ] `src-tauri/icons/` contains the previous file names plus `64x64.png`, all produced from the selected source.
- [ ] `src-tauri/icons/android/` and `src-tauri/icons/ios/` are absent.
- [ ] A 16px view and `32x32.png` still show the tile blocks, with the ground and tiles at the colors in R2.
- [ ] `src-tauri/tauri.conf.json` `bundle.icon` paths still exist and the file is otherwise unchanged.

## Out of Scope

- An in-app logo, about panel, splash screen, or favicon.
- Installer banners, store listing art, and marketing images.
- Theme or layout changes.
- A new Windows build or installer. The exe icon updates on the next `tauri dev` or `tauri build`.
- A code-drawn SVG substitute when image generation fails R4.
